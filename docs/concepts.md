# Concepts for reading the data

WawaPacha follows the ocean signal toward the Peruvian coast, then separates an
institutional state from observations and forecasts. Registry links below own
the factual definitions; this page describes where the site uses them.

## ENSO and the central-Pacific signal

The central-signal views use
[enso-is-ocean-atmosphere-pattern](../evidence/claims.toml),
[oni-definition-and-threshold](../evidence/claims.toml),
[nino-region-definitions](../evidence/claims.toml),
[weekly-nino-anomalies](../evidence/claims.toml) and
[roni-is-current-official-index](../evidence/claims.toml). The homepage opens
with the latest ONI record and story, then shows the sea view and weekly
regional values.

## The Peruvian coast and official state

The coastal views use [icen-definition](../evidence/claims.toml),
[global-and-coastal-can-differ](../evidence/claims.toml) and
[coastal-event-criterion](../evidence/claims.toml). The homepage shows the
coastal explanation and weekly regional values before the official-state
section. The historical route places the coastal index after the sea chronology.
The official-state view uses [enfen-alert-states](../evidence/claims.toml) and
[enfen-magnitude-wording](../evidence/claims.toml).

## Local observations

The local views use
[senamhi-hydrometeorological-stations](../evidence/claims.toml),
[chirps-rainfall-estimates](../evidence/claims.toml),
[chirps-pentad-latency](../evidence/claims.toml),
[era5-historical-reanalysis](../evidence/claims.toml) and
[era5-latency-and-limitations](../evidence/claims.toml). The homepage links to
`/territorio` and `/historico` after the official-state section. The historical
route presents station observations third.

## What to expect

The homepage places the intensity outlook after the local links. It uses
[noaa-enso-strength-probabilities](../evidence/claims.toml) and
[noaa-enso-probability-meaning](../evidence/claims.toml). The separate river
view uses [glofas-river-discharge-forecast](../evidence/claims.toml),
[glofas-ensemble-percentiles](../evidence/claims.toml) and
[glofas-river-point-limits](../evidence/claims.toml).

## Past events

The historical view uses
[historical-coastal-chronology](../evidence/claims.toml). The homepage reaches
historical exploration last. `/historico` presents the sea chronology, coastal
index and station observations in that order.
